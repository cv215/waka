# Controles WAKA

Les vrais tests seront places dans backend/src/test et apps/*/test lorsqu'il y aura du code. Priorites : argent et arrondis, occupation par segment/exclusivite vehicule, droits inter-objets, reprises et paiements inconnus.

Les cas [Q01-Q16](../docs/specifications/WAKA_etats_et_transitions.md) sont les attentes des futurs tests. Une verification documentaire ne constitue pas un test de fonctionnement de WAKA. Aucun faux test vert n'est ajoute a cette arborescence.
